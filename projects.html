PWCC — Risk-Informed Test Adequacy for Autonomous Systems

PhD research · CEA List, Université Paris-Saclay · ASE 2026 · 2025–2026

An open-source tool and replication package that answers "have we tested enough?" for autonomous systems. PWCC learns a Bayesian-network model of the operating domain from fleet data, weights combinatorial coverage by how likely each condition is on the road, and stops testing once the untested share of expected operation falls below a threshold you set — instead of counting every combination as equally important.

  • Command-line tool that runs on your own scenario data and exits non-zero when testing is inadequate — drops into CI as a stopping gate
  • Pre-built Docker image, 31 smoke tests, pinned dependencies — archived on Zenodo under CC BY 4.0

QoS Prediction for Autonomous Vehicles in Edge Computing

AI Research Internship · LAAS-CNRS, Toulouse · 2022–2023

End-to-end machine-learning pipeline that predicts Quality-of-Service degradation for autonomous vehicles operating in dynamic edge-computing environments — enabling proactive intervention before latency incidents occur. Delivered as a versatile real-time prediction API integrated into a larger AV ecosystem.

  • Time-series forecasting models for QoS degradation with high accuracy
  • Production-style REST API for real-time predictions
  • Full engineering thesis (PFE) defended at ESI Algiers
